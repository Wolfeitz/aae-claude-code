# Adaptive Agentic Engineering

Read `AGENTS.md` as the portable AAE entry contract. Use Claude Code's native
instructions, skills, hooks, subagents, MCP, plugins, permissions, and tool
controls when they are relevant. Do not replace a native control with prompt
text or a portable imitation.

For independent review, use the `aae-independent-reviewer` project subagent
only after the target AAE invocation has succeeded.
